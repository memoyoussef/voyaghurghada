VOYAGHURGHADA — CATALOGUE ÉTENDU

FICHIERS
- index.html / style.css / app.js : accueil, sections, catalogue et filtres
- trip.html / trip-details.css / trip-details.js : fiches individuelles des excursions
- trip-details.json : détails et programmes indicatifs des 16 offres
- images/ : copiez ici les images originales du projet (noms de fichiers inchangés)

INSTALLATION
1. Décompressez le ZIP dans un nouveau dossier.
2. Copiez le dossier images de votre ancien site dans ce nouveau dossier.
3. Ouvrez le dossier dans VS Code et démarrez index.html avec Live Server.
4. Cliquez sur « Voir les détails » pour consulter une fiche complète.

PRIX
Les 9 offres d’origine et leurs prix restent présents. Les nouvelles formules sont ajoutées séparément afin de ne pas remplacer les anciennes offres (par exemple, l’excursion Orange Bay existante à 31 € reste distincte de la nouvelle offre en speed boat privé à 36 €).

EXACTITUDE
Les prix sont repris des captures. Les captures ne donnent pas toutes les inclusions, horaires, durées ou conditions : ces éléments sont signalés comme à confirmer et ne sont pas inventés. Le tarif de 14 jours n’est pas lisible/fourni, il est donc affiché « Sur demande ».
